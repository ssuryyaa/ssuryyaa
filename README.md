### RoadSoS · Offline AI Emergency Response

<img src="https://img.shields.io/badge/FIRST%20PLACE-IIT%20MADRAS%20BIMSTEC%202026-F59E0B?style=flat-square&labelColor=0F172A" />

> Road accidents don't wait for signal bars. RoadSoS detects the crash and calls for help with the network switched off.

- **ML-powered offline accident detection** — a model reading smartphone motion sensor data to identify road crashes with no internet connection required
- **Offline-first emergency response** — automatically alerts and connects victims to nearby hospitals, ambulances, police, and rescue services using on-device intelligence and real-time location data
- Built around the **golden hour** — the window where minutes of response time decide survival

<sub><b>Approach</b> · on-device ML · motion sensor telemetry · offline-first architecture · real-time geolocation</sub>
